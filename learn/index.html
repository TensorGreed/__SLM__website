How these pages are tested

  • Real output. Each page shows the date, library versions and CPU it ran on.
  • Comparable numbers. The RAG and embeddings pages share one corpus and 80 frozen questions, so numbers compare across pages.
  • Open source, no API keys, no GPU.
The details

Code blocks are rerun by a script before publishing (by hand for now, not in CI), and the build fails if the code, output or data changed since the last passing run. The corpus is IRS Publication 17; the questions were frozen before any run and are published next to the pages. Differences are tested on the same questions and called suggestive when the test can't separate them. Every pitfall links to its source. Tools: sentence-transformers, rank-bm25, FAISS, scikit-learn, pypdf, open embedding and reranking models pinned to a revision, and a 1.5B open model served by Ollama, all Apache-2.0 or MIT.
