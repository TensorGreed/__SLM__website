    Citations and quoting in RAG answers, and how to check them

    To make a RAG answer checkable, number the passages in the prompt, ask the model to cite the number it used and to quote the sentence it relied on, then verify in code that the cited passage exists and that the quote appears in it word for word. A citation that checks out only proves where the words came from, not that they answer the question, and models follow citation formats more readily than quoting ones. On 80 questions about IRS Publication 17, a 1.5B model on CPU cited a valid passage in 79 answers but marked a quote in only 3, and cited the passage holding the answer in 46 of the 72 answers where that passage had been retrieved.

    Runs on: CPU, about eight minutes for every block on the page once the models are downloaded Updated: 26 Nov 2026

    Tested on 26 Nov 2026 · Python 3.12.3 · sentence-transformers 3.3.1 · transformers 4.46.3 · torch 2.5.1 · rank-bm25 0.2.2 · pypdf 5.1.0 · numpy 2.1.3 · Ollama 0.32.9 · qwen2.5:1.5b-instruct (Q4_K_M) · CPU (20-core Arm, no GPU)

    What a citation has to do

    A citation in a RAG answer is a claim about the prompt: "this sentence came from passage 3". It is only useful if it can be checked, and it can only be checked if the format is fixed. Three parts:

    • Numbered passages. Each retrieved chunk goes into the prompt with an id, [1] to [5], and you keep the map from id to document and page.
    • A citation per claim. The model writes the id after what it took from that passage.
    • A quote. The exact words relied on, in quotation marks. A quote can be verified by string search; a paraphrase can't.

    Then the checks, all plain string work: does every cited id exist? Does each quote occur in the passage it cites? Does it occur in any passage at all? A quote that fails is either paraphrased or invented, and the UI should say so rather than show it as a source.

    Ask for citations, then verify them

    The documents first: IRS Publication 17 (2025) in 512-character chunks, with the 80 frozen questions the RAG pages share.

    import hashlib, json, os, re, urllib.request
from pypdf import PdfReader

if not os.path.exists("p17.pdf"):
    urllib.request.urlretrieve("https://www.irs.gov/pub/irs-prior/p17--2025.pdf", "p17.pdf")
FURNITURE = re.compile(r"^(Userid:|AH XSL/XML Fileid|Page \d+ of \d+|The type and rule above).*$", re.M)

def clean(page):
    page = FURNITURE.sub("", page)                  # proof-sheet lines on every page
    page = re.sub(r"-[ \t]*\n(?=[a-z])", "", page)  # re-join words hyphenated at line ends
    page = re.sub(r"\s*\n\s*", " ", page)
    return re.sub(r" {2,}", " ", page).strip()

def split_keep(text, sep):
    if sep == "":
        return list(text)
    parts = text.split(sep)
    return [p + sep for p in parts[:-1]] + ([parts[-1]] if parts[-1] else [])

def recursive_split(text, size, seps=("\n\n", "\n", ". ", " ", "")):
    if len(text) <= size:
        return [text]
    pieces = []
    for piece in split_keep(text, seps[0]):
        pieces += [piece] if len(piece) <= size else recursive_split(piece, size, seps[1:])
    chunks, buf = [], ""
    for p in pieces:                                # greedy packing, never over size
        if buf and len(buf) + len(p) > size:
            chunks.append(buf)
            buf = ""
        buf += p
    return chunks + [buf] if buf else chunks

text = "\n\n".join(clean(p.extract_text()) for p in PdfReader("p17.pdf").pages)
chunks = recursive_split(text, 512)
starts = [0]
for c in chunks[:-1]:
    starts.append(starts[-1] + len(c))

qs = [q for f in ("pub17-chunking-questions.json", "pub17-more-questions.json")
      for q in json.load(open(f))["questions"]]
gold = []                                           # chunks holding a whole evidence span
for q in qs:
    occ = [m.span() for m in re.finditer(re.escape(q["evidence"]), text)]
    gold.append({j for j, s in enumerate(starts) if any(s <= a and b <= s + len(chunks[j]) for a, b in occ)})
print("sha256:", hashlib.sha256(open("p17.pdf", "rb").read()).hexdigest()[:16], "| chunks:", len(chunks),
      "| questions:", len(qs), "| with a relevant chunk:", sum(map(bool, gold)))

    import json, os, urllib.request

host = os.environ.get("OLLAMA_HOST", "127.0.0.1:11434")      # where `ollama serve` listens
OLLAMA = host if host.startswith("http") else "http://" + host
MODEL = "qwen2.5:1.5b-instruct"                              # `ollama pull qwen2.5:1.5b-instruct`

def chat(prompt, num_predict=120, num_ctx=4096):
    body = {"model": MODEL, "messages": [{"role": "user", "content": prompt}], "stream": False,
            "keep_alive": 0,                                 # unload after each call, so no cached prompt carries over
            "options": {"temperature": 0, "seed": 0, "num_ctx": num_ctx, "num_predict": num_predict,
                        "num_thread": 10}}                   # fastest on this machine; adjust for yours
    req = urllib.request.Request(OLLAMA + "/api/chat", json.dumps(body).encode(), {"Content-Type": "application/json"})
    return json.load(urllib.request.urlopen(req, timeout=900))["message"]["content"].strip()

tags = json.load(urllib.request.urlopen(OLLAMA + "/api/tags"))
print(MODEL, "digest", next(m["digest"][:12] for m in tags["models"] if m["name"] == MODEL))

    Retrieval is the best setup from the reranking page: BM25 and all-MiniLM-L6-v2 fused by RRF, top 30 reranked by a cross-encoder, top 5 kept.

    import numpy as np
from sentence_transformers import SentenceTransformer, CrossEncoder
from rank_bm25 import BM25Okapi

embedder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2", device="cpu",
                               revision="1110a243fdf4706b3f48f1d95db1a4f5529b4d41")
index = embedder.encode([c.strip() for c in chunks], normalize_embeddings=True, batch_size=64)
words = lambda s: re.findall(r"[a-z0-9]+", s.lower())
bm25 = BM25Okapi([words(c) for c in chunks])
ce = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2", device="cpu", revision="233902d25c440f23af6f7d6e94d2946bac0bee0a")

def retrieve(question, k=5):
    qv = embedder.encode(question, normalize_embeddings=True)
    score = {}
    for ranking in (np.argsort(-bm25.get_scores(words(question)))[:100], np.argsort(-(index @ qv))[:100]):
        for r, j in enumerate(ranking, 1):
            score[j] = score.get(j, 0) + 1 / (60 + r)
    pool = sorted(score, key=lambda j: -score[j])[:30]
    return [pool[j] for j in np.argsort(-ce.predict([(question, chunks[j]) for j in pool]))[:k]]

flat = lambda s: " ".join(s.split())
def cited_answer(question, ids):
    passages = "\n\n".join(f"[{n}] {flat(chunks[j])}" for n, j in enumerate(ids, 1))
    return chat("Answer the question using only the passages below, in one or two sentences. After the answer, "
                "give the number of the passage you used in square brackets, like [2], and copy the exact sentence "
                "you relied on from that passage inside double quotes.\n\n"
                f"{passages}\n\nQuestion: {question}", num_predict=160)

def check(answer, ids):
    """Cited ids, whether each id exists, and where each quote was found."""
    norm = lambda s: re.sub(r"\s+", " ", s.replace("’", "'").replace("“", '"').replace("”", '"')).strip().lower()
    cites = [int(n) for n in re.findall(r"\[(\d+)\]", answer)]
    quotes = [q for q in re.findall(r'"([^"]{12,})"', norm(answer))]
    texts = [norm(flat(chunks[j])) for j in ids]
    where = []
    for q in quotes:
        q = q.strip(" .")
        in_cited = any(1 <= n <= len(ids) and q in texts[n - 1] for n in cites)
        where.append("cited passage" if in_cited else "another passage" if any(q in t for t in texts) else "nowhere")
    return cites, [1 <= n <= len(ids) for n in cites], where

q = next(x for x in qs if x["id"] == "q70")["question"]
ids = retrieve(q)
answer = cited_answer(q, ids)
print("Q:", q)
print(answer)
print("check:", check(answer, ids))

    Output

    Q: What number do I call for IRS accessibility services?
[2] If you qualify for their assistance, which is always free, they will do everything possible to help you. Go to T axpayerAdvocate.IRS.gov or call 877-777-4778.
check: ([2], [True], [])

    The example shows both failure modes at once. The model cited [2], which exists, and copied a sentence from it, but without the double quotes it was asked for, so the checker found no quote to verify. And the citation is valid but the answer is wrong: 877-777-4778 is the Taxpayer Advocate Service's number in passage 2, while the accessibility line the question asks about is 833-690-0598. A passing citation check proves where the words came from, not that they answer the question.

    The check normalises curly quotes and whitespace before searching, because the publication uses typographic apostrophes and a model usually writes straight ones. Anything beyond that, such as a changed word, counts as not found.

    Measured: how often citations and quotes check out

    All 80 questions, the same prompt, and the checker above. "Gold cited" means the cited passage is one that holds the question's evidence span (labelled as on the other RAG pages).

    import time
from collections import Counter

stats, where_all, t0 = Counter(), Counter(), time.time()
for i, x in enumerate(qs):
    ids = retrieve(x["question"])
    answer = cited_answer(x["question"], ids)
    cites, valid, where = check(answer, ids)
    stats["has a citation"] += bool(cites)
    stats["every cited id exists"] += bool(cites) and all(valid)
    stats["has a quote"] += bool(where)
    stats["a quote is in the cited passage"] += "cited passage" in where
    gold_ids = [n for n, j in enumerate(ids, 1) if j in gold[i]]
    stats["gold passage retrieved"] += bool(gold_ids)
    stats["gold passage retrieved and cited"] += bool(set(cites) & set(gold_ids))
    where_all.update(where)
print(f"{(time.time() - t0) / len(qs):.1f} s a question\n")
for k, v in stats.items():
    print(f"{k:<34} {v:>3} of {len(qs)}")
print("\nall quotes:", dict(where_all))

    Output (times vary)

    5.3 s a question

has a citation                      79 of 80
every cited id exists               79 of 80
has a quote                          3 of 80
a quote is in the cited passage      3 of 80
gold passage retrieved              72 of 80
gold passage retrieved and cited    46 of 80

all quotes: {'cited passage': 4, 'another passage': 1, 'nowhere': 1}
    • Citing was easy; quoting in the asked format was not. 79 of 80 answers carried a passage number, and every one was in range. Only 3 marked a quote in double quotes; the rest pasted text unmarked, as in the example, or paraphrased. Of the 6 quotes found, 4 were in the cited passage, 1 in a different passage and 1 nowhere.
    • A valid citation often pointed at the wrong passage. The passage holding the answer was in the prompt for 72 questions, and the model cited it for 46. In the other 26 it cited a different passage, which the id check alone would have passed.
    • The check is cheap, and only checks what it can find. It is plain string search, negligible next to the seconds each answer takes to generate. With a model this small it mainly shows that the format wasn't followed; a stricter output format (JSON with a quote field) or a larger model is the fix, and the check then does its job.

    Limits: one 1.5B model and one prompt; larger models generally follow formatting instructions better, which this page does not measure. The checker counts a quote found only after normalising whitespace and curly quotes, and rejects anything else, so a quote with one changed word counts as not found. 80 single-fact questions drafted with an AI assistant, one document.

    Quote first, answer secondMaking the model copy the evidence before answering tends to anchor the answer to it.Answer first
    Extractive answerReturn the best sentence itself (from a reader or reranker) instead of generating: always verbatim, sometimes awkward.Generated
    What to do on a failed checkHide the quote, show the passage instead, or regenerate.Report only
    Match ruleExact after normalisation, or fuzzy (difflib ratio above a threshold). Fuzzy hides small invented changes.Exact after normalisation

    Pitfalls

    • Trusting a citation because it is there. Studies of generative search engines found many citations that don't support the sentence they're attached to (Liu, Zhang and Liang, 2023). Verify in code, as above.
    • Typography breaks exact match. The publication uses ’ and “ ”; models write ' and ". Without normalising, correct quotes fail. With too much normalising (fuzzy matching), invented words pass. The checker above maps curly quotes and whitespace only.
    • Losing the id map. [3] means nothing unless you log which chunk, document and page was third in that prompt. Store the retrieved ids with each answer, as the what is RAG example prints them.
    • Extraction artefacts in the source. pypdf splits some words ("Y ou", "T ax") in this PDF. A model that quotes "You" correctly then fails the check against "Y ou". Clean the text before indexing, or normalise both sides the same way (chunking page).

    In BrewSLM: the documents → Q&A flow drops answer-key questions whose answer the passage doesn't support, and reports how many it dropped.

    Practice

    1. A quote is found in passage 2, but the answer cites [4]. What do you show the user?

    Not the citation as given. Either correct it to passage 2, since the quote proves where the words came from, or flag it. Silently showing [4] presents a wrong source as checked.

    2. Why ask for a quote at all, if the passage id is enough?

    An id says where the model claims it looked; a quote says what it relied on, and only the quote can be checked automatically against the passage. It also lets the UI highlight the sentence for the reader.

    3. Write the condition for "the answer's quote is verbatim in the cited passage".

    After the same normalisation on both sides (whitespace, curly quotes, case): any(quote in passages[n - 1] for n in cited_ids if 1 <= n <= len(passages)), as check does above.
