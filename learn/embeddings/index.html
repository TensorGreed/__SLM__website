Embeddings: text as vectors

An embedding model turns a text into a list of numbers so that texts with related meaning end up close together. Search, RAG retrieval, clustering and deduplication all run on that. These pages cover how the vectors are made, compared, stored, chosen and trained, each with code you can run on a CPU and a measurement on real documents.

Measured on the RAG track's corpus

The measurements reuse the RAG track's material: IRS Publication 17 (2025) in 2,170 chunks of up to 512 characters and 80 frozen questions whose answers are verbatim spans (30 + 50). All models are open, small enough for a CPU, and pinned to a revision; each page names their licences.
